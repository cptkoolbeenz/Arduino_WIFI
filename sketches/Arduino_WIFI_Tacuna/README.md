# Arduino_WIFI_Tacuna

Tacuna/AirLift test sketch from PR #1.

Open this folder in Arduino IDE:

```text
sketches/Arduino_WIFI_Tacuna/Arduino_WIFI_Tacuna.ino
```

Do not move `Arduino_WIFI_Tacuna.ino` to the repo root; Arduino IDE compiles all `.ino` files in one sketch folder together.

Before compiling, copy `secrets.example.h` to `secrets.h` in this folder and set the WiFi/controller values for the test network.

See `AIRLIFT_PORT.md` for the required Adafruit AirLift Shield pin modifications and bench-test notes.
